# Naver Synchronization

Imports events from Naver Calendar into Nextcloud calendars over CalDAV, one way.

Sign in with a Naver ID and password, and choose which calendars to import when the account has more than one. Local edits are reverted on the next sync, and events that exist only in Nextcloud are removed.

- App id: `naversynchronization`
- Issues: https://github.com/chanha0406/naver-synchronization/issues
